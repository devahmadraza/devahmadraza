## 🚀 Featured Projects

### 1. Taskly — MERN Todo App

A full-stack task management application that allows users to register, log in, and manage their personal tasks securely.

**Key Features**
- 🔐 JWT-based authentication and protected routes
- 🔑 Password hashing and authentication middleware
- ✅ Create, read, update, and delete tasks
- 👤 User-specific task isolation
- 📱 Responsive interface built with React
- 🔔 Toast notifications and form validation
- ☁️ Frontend deployed on Vercel and backend on Render

**Tech Stack:** React, Vite, Node.js, Express, MongoDB, Mongoose, JWT

**Links:** [Live Demo](https://taskly-todo-three.vercel.app) · [Source Code](https://github.com/devahmadraza/Taskly-Todo)
